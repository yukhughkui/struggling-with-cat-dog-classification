## 2. 绝对路径、Windows 写法、中文路径、盘符假设

### 2.1 绝对路径清单（就是上面第 1 节那几处）

- `d:\DeepStudy\Project1\Cat_Dog_data`：出现在 4 个文件里。
- `D:\DeepStudy\Anaconda\envs\torch_env\python.exe`：出现在 `一键复现.py:41`。
- 另外 `README.md:34`、`README.md:51`、`check_data.py:3`（用法注释）里也有旧的 `d:\...`，属于文档/注释，不影响运行。

### 2.2 Windows 专有写法

| 位置 | 内容 | 会不会影响非 Windows |
|---|---|---|
| 所有路径 | 用 `pathlib.Path` 拼接 | 不影响，Linux/macOS 会自动用 `/` |
| `prepare_cache.py:87`、`109` | `multiprocessing.Pool` + `if __name__ == "__main__"` | 不影响；`spawn`（Windows/macOS）和 `fork`（Linux）都能跑 |
| `run_experiments.py:82` | `num_workers` 默认 0，注释提到 Windows spawn 慢 | 不影响；Linux 上可手动 `--num-workers 4` 提速 |
| `src/plots.py:16` | 字体 `Microsoft YaHei` / `SimHei` | **有影响**：Linux 默认没有这两个字体，中文标题会变方块 |
| `一键复现.py` | 用 `sys.executable`、`subprocess`、`isatty()` | 都是跨平台的 |

结论：**没有 `.bat`、没有 `os.startfile`、没有 `winreg`、没有反斜杠硬编码在路径拼接里**。核心代码本身是跨平台的，主要障碍是“数据路径”和“中文字体”。

### 2.3 中文路径 / 中文文件名

- 项目里有中文文件名：`一键复现.py`、输出目录里的中文报告名、提交材料 zip 名。Python 3 和 Windows 都没问题。
- 但**打包/解压工具**可能用 GBK 处理 zip 文件名，导致对方解压后文件名乱码。建议：
  - 用 7-Zip 或系统自带压缩，勾选 UTF-8 文件名；
  - 或者把 `一键复现.py` 临时改名为 `run_all.py` 再发（脚本内容不用改）。
- 数据路径里**尽量不要带中文和空格**。带空格必须加引号（PowerShell 里也一样）：
  ```powershell
  python check_data.py "E:\My Data\Cat_Dog_data"
  ```
- `一键复现.py` 启动子进程时设置了 `PYTHONIOENCODING=utf-8`，中文输出不会乱码；直接跑单个脚本时，Windows 控制台一般也能正常显示。

### 2.4 盘符假设

`d:\` 只在上面列出的默认值里出现。代码没有假设“必须 D 盘”，只要把那 4 处改掉，放 C/E/F 盘都可以。

| 磁盘 | 缓存约 5GB + 输出约 1GB + 环境约 3~5GB |

### 3.2 `requirements.txt` 够不够用？

当前内容：

```
torch>=2.0
torchvision>=0.15
numpy>=1.24
scikit-learn>=1.3
matplotlib>=3.7
Pillow>=10.0
```

**包名是够的**：代码只 import 这 6 个（`sklearn` 只用了 `confusion_matrix`，`Pillow` 用于解码）。没有 pandas、tqdm 等隐藏依赖。

**但直接 `pip install -r requirements.txt` 有三个坑**：

1. **会装成 CPU 版 torch**。Windows 上 PyPI 的 `torch` 默认不带 CUDA。要用 GPU 必须从 PyTorch 官方源装：
   ```powershell
   pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu118
   ```
   （RTX 50 系列显卡请改用 `cu128` 源；cu118 不支持 sm_120。）
2. **版本下界太松**。`torch>=2.0` 可能装到 2.0/2.1，而代码用了 `torch.amp.GradScaler("cuda")`、`torch.amp.autocast("cuda")` 这些较新的接口；`torchvision>=0.15` 也可能和 torch 版本不匹配。**建议直接锁到 2.7.1 / 0.22.1**。
3. **numpy 2.x 与老 torch 可能不兼容**。锁了 torch 之后基本没这个问题。

**建议把 `requirements.txt` 改成：**

```
torch==2.7.1
torchvision==0.22.1
numpy>=1.24,<3
scikit-learn>=1.3
matplotlib>=3.7
Pillow>=10.0
```

然后在 GPU 机器上按“先 torch 后其余”的顺序装：

```powershell
# 1) CUDA 版 torch（这行会同时装 torchvision）
pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu118

# 2) 其余依赖
pip install numpy scikit-learn matplotlib Pillow
```

> 如果直接 `pip install -r requirements.txt`，pip 可能用 PyPI 的 CPU 版覆盖掉刚装好的 CUDA 版。装完务必用 3.4 节的命令确认 `torch.cuda.is_available()` 是 True。

### 3.3 没有 GPU 会怎样？

代码有完整的 CPU 兜底：

- `src/runner.py:55`、`156`：`torch.device("cuda" if torch.cuda.is_available() else "cpu")`
- `use_amp=(device.type == "cuda")`：CPU 上自动关闭混合精度
- `GradScaler("cuda", enabled=False)`：禁用状态下不会初始化 CUDA
- `torch.cuda.reset_peak_memory_stats` 只在 `device.type == "cuda"` 时调用

所以**能跑，但会非常慢**：

| 场景 | 大致时间 |
|---|---|
| RTX 4070 8GB（本机） | 15 个 run 约 1.7 小时（缓存另算 5.5 分钟） |
| 6GB 笔记本显卡 | 略慢，可能 2~3 小时；大 FC 的 batch 48 可能显存紧张 |
| 纯 CPU | 单 epoch 可能十几分钟到几十分钟，15 个 run 需要数小时到十几小时 |

CPU 上建议先只跑一个种子验证流程：

```powershell
python run_experiments.py --only transfer --seeds 42 --epochs-a 1 --epochs-b 1 --force
```

显存不足时把 batch 调小（会影响结果，需在报告里说明）：

```powershell
python run_experiments.py --only e1 e7 --seeds 42 43 44 --batch-size 24 --epochs-cnn 12 --epochs-heavy 12 --force
```

```powershell
python -c "import sys, torch, torchvision, numpy, sklearn, matplotlib, PIL; print('Python', sys.version.split()[0]); print('torch', torch.__version__); print('torchvision', torchvision.__version__); print('CUDA', torch.cuda.is_available()); print('GPU', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

### 3.6 字体（Linux/macOS 必看）


### Step 6：正式训练（约 1.7 小时 / GPU）

严格按 README 的两条命令（先迁移、后自搭 CNN）：


- 第一条：6 个 ResNet18 run（阶段 A 6 epoch + 阶段 B 8 epoch），约 13 分钟。
- 第二条：9 个自搭 CNN run（E1 6 个 + E7 3 个，batch 48、12 epoch），约 85~90 分钟。
- `--force` 表示覆盖已有结果。第一次跑其实加不加都行，加了更省心。
- 中断后重新执行同一条命令即可：`metrics.json` 已存在的 run 会跳过。
- **不要漏掉 `--epochs-cnn 12`**：默认是 20，跑出来的结果和报告不可比。

## 6. 常见报错对照

| 现象 | 原因 | 处理 |
|---|---|---|
| `FileNotFoundError: 数据目录不符合 ImageFolder 结构` | `data_root` 没改或路径写错 | 改第 1.1 节的 4 处；确认 `train/cat` 存在 |
| `No module named 'torch'` | 用了系统 Python，不是装 torch 的环境 | 在编辑器中选对解释器；或激活虚拟环境 |
| `CUDA False` / 训练极慢 | 装了 CPU 版 torch | 按 3.2 用官方 CUDA 源重装 |
| `CUDA out of memory` | 显存不够（batch 太大） | `--batch-size 24` 或 16 |
| 第一个 batch 等几分钟、GPU 0% | `num_workers` 太多，Windows 每个 worker 重新 import torch | 保持 `--num-workers 0`（默认） |
| 图里中文变方块 | 缺中文字体 | 见 3.6；Windows 一般不会 |
| `mat1 and mat2 shapes cannot be multiplied` | 改了输入尺寸但没改模型里的 `14*14` | 输入保持 224，或同步改 `src/models.py` |
| `RuntimeError: ... bootstrapping phase` | Windows 多进程没有 `__main__` 保护 | `prepare_cache.py` 已有保护，别把 `main()` 写到模块顶层 |
| `检查通过` 没出现、一键脚本中止 | 数据数量/目录不符 | 改 `check_data.py:11-12` 的 EXPECT，或换正确数据 |
| 汇总表里 `test_acc` 是 nan | 只训练没做最终评估 | 不加 `--skip-final-eval`，或补跑 `run_experiments.py --force` |
| 双击 `.py` 一闪而过 | 没装 Python 或关联错解释器 | 用编辑器 ▶；或命令行 `python 一键复现.py` |
| 解压后中文文件名乱码 | zip 编码问题 | 用 7-Zip 解压，或把 `一键复现.py` 改名 `run_all.py` |
