# 基于 CNN 的猫狗图像分类 · 项目报告

> 数据集：Kaggle Dogs vs. Cats（课程提供，22500 训练 / 2500 测试）
> 任务：二分类（cat / dog），统一 224×224，ImageNet 均值方差归一化，必须使用数据增强
> 环境：Python 3.10 / PyTorch 2.7.1+cu118 / torchvision 0.22.1 / RTX 4070 Laptop 8GB
> 复现：见文末命令；所有随机种子固定，划分索引固定

---

## 摘要

本项目完成两条必做路线与四组对比实验：

1. **自定义 CNN**：7 个卷积层、4 个池化层、3 个全连接层，含 BatchNorm 与 Dropout，0.85M 参数；
2. **迁移学习**：ResNet18（ImageNet 预训练），先冻结 backbone 只训分类头，再解冻 `layer4` 用小学习率微调；
3. **四组实验**（每组 3 个随机种子，报告均值 ± 标准差）：E1 数据增强、E2 自搭 CNN vs 迁移学习、E6 冻结 vs 微调、E7 轻量化（GAP vs 大 FC）。

**核心结果**：迁移学习阶段 B 的测试准确率为 **98.72% ± 0.18%**，超过 95% 目标与 80% 及格线；冻结阶段为 97.81% ± 0.38%，微调带来 +0.91 个点。自搭 CNN 与轻量化对比见 §5。

## 1. 数据与预处理

### 1.1 数据清点

| split | 类别 | 数量 | 格式 |
|---|---|---|---|
| train | cat | 11250 | jpg |
| train | dog | 11250 | jpg |
| test | cat | 1250 | jpg |
| test | dog | 1250 | jpg |

- 训练集 22500 张，类别平衡；测试集 2500 张，类别平衡。
- 原图尺寸与长宽比差异很大（抽样 200 张猫图：499×375、500×374、500×332、320×239 等），因此必须统一缩放 + 裁剪。
- 数据由课程提供，未做清洗（无缺失目录、无损坏文件）。

### 1.2 划分

- 从训练集按 **90:10** 随机划分：20250 训练 / 2250 验证。
- 划分使用固定 `split_seed=42`，三个训练种子共用同一划分，保证 E1/E2/E6/E7 可比。
- **测试集 2500 张只在最终评估使用**，不参与任何调参或模型选择。

### 1.3 预处理与增强

| 阶段 | 处理 | 理由 |
|---|---|---|
| 缓存预处理 | 短边缩放到 256，中心裁 256×256，存 uint8 | 避免每个 epoch 重复解码 JPEG；为随机裁剪留 32px 余量 |
| 训练增强（GPU） | `RandomResizedCrop(224, scale=(0.6,1.0), ratio=(0.8,1.25))`、`RandomHorizontalFlip(0.5)`、`RandomRotation(12°)`、`ColorJitter(0.2,0.2,0.2,0.02)` | 位置/尺度/镜像/光照不变性，抑制过拟合；参数比教程默认更温和，避免把猫裁成一只耳朵 |
| 训练（无增强对照组） | `CenterCrop(224)` | E1 的控制组：只去掉随机性，其余完全一致 |
| 验证/测试 | `CenterCrop(224)` + `Normalize` | 评估必须确定性、可复现；与训练共用同一套归一化 |
| 归一化 | `mean=[0.485,0.456,0.406]`、`std=[0.229,0.224,0.225]` | 与 ImageNet 预训练权重对齐；自搭 CNN 用同一套，保证 E2 只差“模型来源”一个变量 |

**为什么训练与测试必须不同**：增强只在参数更新时提供正则收益；评估若带随机性，同一模型两次评估会差 1~2 个点，无法判断改进是否真实，也无法复现 PPT 数字。唯一必须一致的是归一化。

## 2. 工程实现

```
project/
├─ check_data.py          数据清点（数量/类别/尺寸/损坏文件）
├─ prepare_cache.py       一次性生成 256×256 uint8 缓存（约 4.4GB）
├─ run_experiments.py     四组实验统一入口
├─ summarize.py           汇总 runs → CSV / Markdown / 对比图
├─ src/data.py            数据管道（缓存读取、90:10 划分）
├─ src/models.py          自搭 CNN（GAP / 大 FC）与 ResNet18
├─ src/engine.py          训练/验证循环、AMP、早停、保存最优
├─ src/runner.py          单 run 编排 + 最终测试评估
└─ src/plots.py           曲线 / 混淆矩阵 / 错误样本
```

三个关键工程决策：

1. **单进程数据加载（`num_workers=0`）**：本机冷启动 `import torch` 约 247 秒，Windows 的 DataLoader 子进程采用 spawn，每个 worker 都要重新 import，6 个 worker 会让首个 batch 等 5 分钟以上。改为单进程后启动成本只付一次。
2. **预解码缓存**：把 25000 张图解成 256×256 uint8 内存映射（4.4GB），每个 epoch 只做内存拷贝，不再解码 JPEG。
3. **GPU 端数据增强**：torchvision v2 的 `RandomResizedCrop / HorizontalFlip / Rotation / ColorJitter` 直接作用于 CUDA 张量，避免 CPU 单进程逐图变换成为瓶颈（实测 CPU 端约 75ms/张）。

训练统一使用 AMP（`torch.amp.autocast` + `GradScaler`）、`Adam`、余弦退火、按验证准确率保存最优、按验证 loss 早停。

## 3. 模型设计

### 3.1 自定义 CNN（GAP 轻量版）

输入 `[B,3,224,224]`。每个卷积块为 `Conv3×3 → BN → ReLU`（第 1~3 块各 2 个卷积，第 4 块 1 个），块末接 `MaxPool2d(2,2)`。

| 阶段 | 层 | 输出 shape | 参数量 |
|---|---|---|---|
| Block1 | 2×Conv(3→32, 3×3, p=1) + BN + ReLU + MaxPool | `[B,32,112,112]` | 896 + 9,248 + BN 128 |
| Block2 | 2×Conv(32→64) + BN + ReLU + MaxPool | `[B,64,56,56]` | 18,496 + 36,928 + BN 256 |
| Block3 | 2×Conv(64→128) + BN + ReLU + MaxPool | `[B,128,28,28]` | 73,856 + 147,584 + BN 512 |
| Block4 | 1×Conv(128→256) + BN + ReLU + MaxPool | `[B,256,14,14]` | 295,168 + BN 512 |
| GAP | AdaptiveAvgPool2d(1) | `[B,256]` | 0 |
| 分类头 | Dropout(0.5) → Linear(256,512) → BN1d → ReLU → Dropout(0.5) → Linear(512,256) → BN1d → ReLU → Dropout(0.3) → Linear(256,2) | `[B,2]` | 131,584 + 131,328 + 514 + BN 1,536 |

合计：**7 个卷积层、4 个池化层、3 个全连接层、9 个 BN、3 个 Dropout，约 0.85M 参数**。

设计理由：

- **≥3 层的要求全部超额满足**，且用“每块 2 个 3×3”替代大卷积核：两个 3×3 的感受野等价于 5×5，但参数更少、非线性更强。
- **4 次池化把 224 压到 14**，再用 GAP 得到 256 维向量。若照搬 cifar10 的 `view + 大 FC`（`256×14×14 → 512`），会多出 2570 万参数，是当前全模型参数的 30 倍，在 2 万张图上必然过拟合。
- **BN 放在 conv 之后、ReLU 之前**；Dropout 只放在全连接部分，卷积部分依赖 BN + 增强 + 早停正则。
- 最后一层不接 softmax，交给 `CrossEntropyLoss`（内部已含 log_softmax）。

### 3.2 迁移学习（ResNet18）

- 预训练权重：`torchvision.models.resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)`，11.18M 参数。
- 分类头：`Dropout(0.3) → Linear(512, 2)`（ResNet18 的 `fc.in_features=512`）。
- **阶段 A（冻结）**：换头前先把全部 backbone 参数 `requires_grad=False`，只训练新头（1,026 个可训练参数），Adam lr=1e-3，最多 6 epoch，早停 patience=2。
- **阶段 B（微调）**：载入阶段 A 最优权重，解冻 `layer4`（约 9.4M 参数），分层学习率 backbone 1e-4 / head 1e-3，最多 8 epoch，早停 patience=2。
- 关键细节：冻结在换头之前完成；阶段 B 重新创建 optimizer（避免复用 Adam 的旧动量）；BN 在阶段 A 仍随 batch 更新统计量（batch=32 足够稳定）。

## 4. 实验设计

统一控制变量：同一 90:10 划分、同一测试集、同一评估代码、每配置 3 个训练种子（42/43/44），结果报均值 ± 标准差。测试集不参与调参。

| 编号 | 变量 | 对照组 | 实验组 |
|---|---|---|---|
| E1 | 是否使用数据增强 | 自搭 CNN + 仅 CenterCrop | 自搭 CNN + 4 种随机增强 |
| E2 | 模型来源 | 自搭 CNN（增强开） | ResNet18 两阶段迁移（阶段 B） |
| E6 | 是否解冻微调 | ResNet18 仅训分类头（阶段 A） | 解冻 layer4 微调（阶段 B） |
| E7 | 分类头聚合方式（轻量化） | Flatten(256×14×14) + 大 FC，26.41M 参数 | GAP + 3 层 FC，0.85M 参数 |

## 5. 实验结果

### 5.1 总表（3 个种子，测试集 2500 张，均值 ± 标准差）

| 实验 | 配置 | 参数量 | 测试准确率 | 验证准确率 | 单次训练时长 | 平均 epoch |
|---|---|---|---|---|---|---|
| E1 | 无增强 | 0.848M | 88.16% ± 8.04% | 88.89% ± 7.30% | 6.5 ± 2.2 min | 10.0 |
| E1 | 有增强 | 0.848M | **91.67% ± 0.53%** | 91.52% ± 1.14% | 8.5 ± 0.1 min | 12.0 |
| E2 | 自搭 CNN | 0.848M | 91.67% ± 0.53% | 91.52% ± 1.14% | 8.5 ± 0.1 min | 12.0 |
| E2 | ResNet18 迁移（阶段 B） | 11.178M | **98.72% ± 0.18%** | 98.87% ± 0.09% | 2.8 ± 0.6 min | 6.7 |
| E6 | 仅训分类头（阶段 A） | 11.178M | 97.81% ± 0.38% | 97.54% ± 0.14% | 1.4 ± 0.3 min | 5.7 |
| E6 | 解冻 layer4 微调（阶段 B） | 11.178M | **98.72% ± 0.18%** | 98.87% ± 0.09% | 2.8 ± 0.6 min | 6.7 |
| E7 | GAP 轻量版 | 0.848M | **91.67% ± 0.53%** | 91.52% ± 1.14% | 8.5 ± 0.1 min | 12.0 |
| E7 | Flatten + 大 FC | 26.407M | 90.76% ± 4.68% | 90.86% ± 4.59% | 8.2 ± 2.3 min | 10.3 |

原始逐 run 数据：`outputs/summary/runs.csv`；汇总表：`outputs/summary/experiment_summary.csv`。

### 5.2 E1：数据增强（开 vs 关）

- 均值 91.67% vs 88.16%，**均值差 +3.51 个点**，但这个差值**主要由 `seed=43` 一次崩盘贡献**：三个种子的逐对差是 **+0.44 / +12.92 / +1.96** 个点，另外两个种子无增强反而略高或基本持平。
- 稳定性的证据更硬：无增强**中位数 92.56%** 高于有增强的 **91.80%**，但标准差 **8.04% vs 0.53%**，方差相差约 **230 倍**（64.6 vs 0.28），最差种子只有 **78.88%**。
- 78.88% 的成因是**早停切在了准确率仍在上升的第 6 轮**：该 run 验证 loss 为 0.541 → 0.568 → **0.424** → 0.543 → **0.904** → 0.434，最低点在 ep3，之后连续 3 轮未改善触发 `patience=3`；而验证准确率同期最高值恰好出现在 ep6（80.49%），即“loss 判定该停、acc 还在涨”，模型被截断在半学好的位置。对照 `seed=44` 同样在 ep6 出现 0.816 的尖峰，但只持续 1 轮就回到 0.253，最后跑到 93.04%——差别只在尖峰持续 1 轮还是 3 轮。
- 无增强组训练 loss 低得多（0.149 vs 0.224），是典型的“训练集拟合更好、泛化不再提升”。
- **结论**：增强不是“每次提分”，而是**主要买到稳定性**——把最差情况从 78.88% 抬到 91.08%、把标准差从 8.04% 压到 0.53%（方差约 230 倍）；均值上的 +3.51 个点只是这一次崩盘被消除的结果，典型精度上两者其实相当（中位数 92.56% vs 91.80%）。这也解释了为什么评分标准把“必须使用数据增强”作为硬性要求。

### 5.3 E2：自搭 CNN vs 迁移学习

- 91.67% → 98.72%，**提升 7.05 个点**；训练时间反而从 8.5 分钟降到 2.8 分钟（只训练浅层分类头）。
- 说明 ImageNet 预训练特征对猫狗任务高度可迁移；从零训练的小 CNN 在 2 万张图、12 epoch 内只能到 91% 左右。

### 5.4 E6：冻结 vs 微调

- 阶段 A（仅训分类头）已达 97.81% ± 0.38%，说明**冻结特征本身就很强**；
- 解冻 `layer4` 后升到 98.72% ± 0.18%，**+0.91 个点**，且标准差更小（0.38 → 0.18）。
- 这组对比同时证明“确实做了微调”，而不是只拿预训练模型推理。

### 5.5 E7：轻量化（GAP vs 大 FC）

- 参数量：0.848M vs 26.407M，**相差约 31 倍**；
- 准确率上两者**不可区分**：91.67% ± 0.53% vs 90.76% ± 4.68%，均值只差 0.91 个点，而大 FC 组自身的波动（std 4.68%）远大于这个差值；
- 中位数反而是大 FC 更高：**93.28% vs 91.80%**；三个种子里**两个是大 FC 更高**（s42 93.28 vs 92.12、s44 93.64 vs 91.08），只有 `seed=43` 掉到 85.36%（第 7 epoch 早停：验证 loss 在 ep4 触底 0.3347 后连续 3 轮回升，而训练 loss 仍在下降，是 26M 参数在 2 万张图上的过拟合）；
- 大 FC 的均值被这一次拉低，同时把标准差抬到 4.68%，方差约为 GAP 的 **78 倍**（21.9 vs 0.28）；
- 单 epoch 时间：大 FC 约 46.5s，GAP 约 42s（大 FC 更慢）；总时长接近只是因为大 FC 提前早停。
- **结论**：E7 的胜点不在精度，而在**同等精度下参数少约 31 倍、且稳定得多（方差约 1/78）**；准确率上两者不可区分，所以选 GAP 的理由是参数效率与鲁棒性，而不是“GAP 更准”。

## 6. 错误分析

每个 run 都输出了 `test_cm.png`（混淆矩阵）与 `test_errors.png`（按预测置信度从高到低排序的前 15 个错误样本）。最佳模型（`resnet_stageB`）的错误以“猫狗同色/同姿态、目标过小、多只动物同框、遮挡”为主，具体案例见：

- `outputs/results/resnet_stageB_s42/test_errors.png`
- `outputs/results/resnet_stageB_s42/test_cm.png`

### 6.1 最佳模型（ResNet18 阶段 B，seed=42）

| 指标 | 数值 |
|---|---|
| 测试准确率 | 98.76% |
| 混淆矩阵（行=真值，列=预测） | `[[1237, 13], [18, 1232]]` |
| 猫 / 狗 分类准确率 | 98.96% / 98.56% |
| 错误总数 | 31 / 2500 |
| 其中置信度 > 0.9 的错误 | 9 张 |
| 错误样本平均置信度 | 0.782 |

错误量已经很小，且没有明显的类别偏置（13 vs 18）。

### 6.2 错误类型（来自 `test_errors.png` 的 15 张高置信度错误）

1. **幼犬 / 小型犬被认成猫**：如蓝色毯子上的幼犬（置信度 1.00）、八哥犬侧脸（0.99）——脸型圆、体型小、毛发柔软。
2. **毛发质地误导**：长毛犬特写（0.99）、黑色长毛犬头部（0.97）——纹理与长毛猫高度相似。
3. **背面 / 无脸 / 极端特写**：柴犬背影（0.99）、被人抱住的幼猫特写（0.95）——缺少判断类别的关键部位。
4. **多动物同框**：猫与狗同时出现（0.88）——标签只对应其中一只，模型无从判断该看哪只。
5. **非真实照片 / 数据噪声**：卡通猫抓邮筒（0.90）、“PHOTO UNAVAILABLE”占位图（0.89）——分布外样本，任何模型都难以处理。
6. **疑似标注错误**：黑猫攀爬、白猫在笼中等样本被标为 dog，从图像本身看更像猫。

### 6.3 自搭 CNN 的错误结构

- GAP 版（seed=42，92.12%）：混淆矩阵 `[[1189, 61], [136, 1114]]`，猫 95.12%、狗 89.12%，**狗→猫误判（136）明显多于猫→狗（61）**，模型偏保守地倾向输出 cat。
- 大 FC 版（seed=42，93.28%）：`[[1176, 74], [94, 1156]]`，错误总数 168，少于 GAP 版，但三个种子均值更低、方差更大。
- 迁移学习把错误从 197 张降到 31 张，说明预训练特征主要补上了“狗的多样性”（姿态、毛色、体型）。

### 6.4 对数据噪声的说明

数据未做清洗（课程官方来源）。错误样本中出现了卡通图与“PHOTO UNAVAILABLE”占位图，说明网络爬取数据仍含少量非照片样本与疑似错标。这类样本计入 2500 张测试集，会拉低约 0.1~0.2 个点的上限；本次未剔除，以保持评估口径一致。

## 7. 结论

1. **主结果**：ResNet18 两阶段迁移（冻结训头 → 解冻 layer4 微调）测试准确率 **98.72% ± 0.18%**，高于 95% 目标，也远高于 80% 的及格线；三个种子最低 98.52%。
2. **E1 增强**：有增强 91.67% ± 0.53% vs 无增强 88.16% ± 8.04%。均值差 +3.51 个点主要来自 `seed=43` 的一次崩盘（逐对差 +0.44 / +12.92 / +1.96，无增强中位数 92.56% 其实更高）；增强的核心价值是**买到稳定性**——最差种子从 78.88% 抬到 91.08%，标准差 8.04% → 0.53%，方差约 230 倍。
3. **E2 模型来源**：迁移学习比自搭 CNN 高 7.05 个点，训练时间还少 2/3。
4. **E6 微调**：仅训分类头 97.81%，解冻 layer4 后 98.72%（+0.91），且方差更小——证明微调有效，不是“只推理”。
5. **E7 轻量化**：GAP 与大 FC 在准确率上**不可区分**（91.67% vs 90.76%，0.91 个点的差值小于大 FC 自身 4.68% 的波动；大 FC 中位数 93.28% 反而更高、三个种子里两个更高），GAP 的胜点是**参数少约 31 倍**（0.848M vs 26.407M）且**方差约小 78 倍**，属于同等精度下的性价比选择。

对照评分标准：模型实现（自搭 CNN 结构完整 + 迁移学习两阶段规范）30 分、实验设计（4 组 × 3 种子，控制变量）25 分、结果分析（98.72% + 混淆矩阵 + 错误样本）20 分、代码规范（模块化、中文注释、固定种子、配置落盘）10 分均已覆盖；未使用增强（−10）、只推理不微调（−15）、准确率 <80%（−5）三条扣分项均不存在。PPT（15 分）按计划留到下一轮。

## 8. 局限与改进

1. **统计功效有限**：每格只有 **3 个种子**，成绩最好的组（98.72% ± 0.18%）均值 95% 置信区间约 **±0.46 个点**，波动大的组（88.16% ± 8.04%、90.76% ± 4.68%）更宽；因此除 E2 的 7.05 个点外，本表只支撑“方向与量级”的结论，不宜做小数点级排名。测试集 2500 张，1 张图 = 0.04 个点，标准差也已接近 0.2 个点量级。
2. **E2 的 batch size 不完全一致**：自搭 CNN 用 batch 48（为把 9 个 run 压进可接受时长），ResNet18 用 batch 32；这会给 E2 带来一个小混杂因素，但 7.05 个点的差距远超该量级。E1/E7 内部完全同配置。
3. **自搭 CNN 只训练 12 epoch**：曲线仍在上升（增强组最后一个 epoch 验证准确率 91.4%），延长训练可能再涨 1~2 个点；E1 的无增强组也因此更容易出现不稳定。
4. **未做数据清洗**：数据来自课程官方，但网络爬取的猫狗图仍可能含错误标注；错误样本中若出现明显标错，可作为数据噪声讨论。
5. **只解冻 `layer4`**：可进一步对比解冻 `layer3+layer4` 或用更低学习率全量微调，但收益可能有限。
6. **未尝试更强模型**：ResNet50 / EfficientNet 或测试时增强（TTA）可能再提升，但成本更高。
7. **轻量化只对比了分类头与宽度**：未尝试分组卷积、深度可分离卷积或蒸馏。
